## Open in VS Code
1. Download and unzip this folder.
2. In VS Code, choose **File > Open Folder**.
3. Select the unzipped `Project_Three_Jayven` folder.
4. Open `index.html` to inspect the homepage.

## Before submitting
- Check the Google Maps API key and make sure the Google Maps JavaScript API is enabled for it in Google Cloud. Google may require billing and key restrictions. Do not post an unrestricted key publicly.
- Test every navigation link, the audio player, the Questions button, and map features.
- Validate all four HTML files with the W3C HTML Validator.
- Validate `styles.css` with the W3C CSS Validator. The assignment requests eight screenshots total: one HTML and one CSS validation for each website page. If the CSS file is shared, submit the CSS validation evidence as instructed by your instructor.
- Upload the files and folders while keeping this exact folder structure.
- Enable GitHub Pages for the Project Three repository and test the published links.
